# Rachador

## 01 — O que é

O **Rachador** é um web app responsivo para grupos de amigos registrarem despesas compartilhadas, calcularem automaticamente quem deve para quem e acompanharem a quitação dos valores. A proposta é reduzir o tempo gasto fazendo contas e cobrando pagamentos depois de viagens ou outros gastos em grupo.

## 02 — Para quem

Feito principalmente para **grupos de amigos em viagens de vários dias** que dividem despesas como alimentação, transporte, hospedagem e compras em conjunto.

## 03 — Como rodar

O projeto usa **TypeScript + React + Vite** no front-end e **Supabase (Postgres)** como banco de dados.

> Os arquivos fornecidos ainda não definem o repositório nem documentam os comandos exatos de execução. Em um projeto Vite padrão, o fluxo normalmente é instalar as dependências e iniciar o servidor de desenvolvimento com os scripts definidos no `package.json`.

## 04 — O que precisa

- Node.js e um gerenciador de pacotes compatível com o projeto
- Projeto/configuração do Supabase
- Variáveis de ambiente necessárias para conectar a aplicação ao Supabase
- Banco com as estruturas principais de **grupo**, **participante**, **despesa** e **divisão**

A versão v1 não prevê integração bancária real: a chave Pix é apenas um campo de texto livre.
